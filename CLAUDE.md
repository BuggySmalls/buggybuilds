# cerealbowlers.org — league commissioner playbook

Nick runs Cereal Bowlers, a Wednesday bowling league at Kingstown Bowl (North Kingstown, RI) and manages it entirely by chatting with Claude. Claude is the admin: Nick sends scores (often a photo of the scoring screen), roster changes, nicknames, commentary and award picks; Claude edits the data files, checks them, and pushes to `main`. Cloudflare Workers Builds deploys `public/` automatically about a minute after each push.

## Files
- `public/data/league.json` — the only real data. League settings, roster, events, announcements, power-ranking commentary, manual awards, custom records, photos.
- `public/data/sample.json` — preview data: the real roster with made-up scores (`node scripts/make-sample.mjs` rebuilds it from the current roster). Shown only while `"sampleMode": true` in league.json. **Set `sampleMode` to `false` before the first real night (Oct 21, 2026)** unless Nick says otherwise.
- `public/js/engine.js` — every stat is derived here from raw results. Never store computed stats in the data files.
- `public/js/app.js`, `public/js/charts.js`, `public/css/site.css` — the site (version 3, 90s bowling alley design, live since Oct 14 2026). Served at cerealbowlers.org (never link to buggybuilds.org anywhere on the site).
- `public/v1/` and `public/v2/` — earlier designs kept viewable at /v1/ and /v2/, reading the same live data. The `version-1` branch is the exact saved copy of version 1. Don't change these unless Nick asks.
- `src/worker.js` — bowler accounts (Oct 21 2026). Only `/api/*` runs code; everything else is static. Accounts live in a Durable Object (SQLite) called `Accounts`, created by the `migrations` entry in `wrangler.jsonc` — never remove or rename that migration.
- `public/js/account.js` — sign up (#/join), sign in (#/login) and edit profile (#/me) screens.
- `scripts/validate.mjs` — run before every push. `scripts/test.mjs` — run after any engine change.

## Logging a night
Add (or update) one entry in `events`, keyed by date:
```json
{ "date": "2026-10-21", "status": "completed",
  "scores": { "buggy": [182, 201, 167], "adam": [145, 160, null] },
  "frames": { "buggy": ["X 7/ 81 9- X X 54 6/ X X8/", "…", "…"] },
  "note": "optional one-line note shown on the results page" }
```
- `scores`: up to 3 games per bowler, `null` for a missed game. Leave out anyone who didn't bowl.
- `frames` (optional, per game): 10 space-separated frames. `X` strike, `/` spare, digits, `-` miss, `G` gutter, `F` foul. Prefix `S` when the first ball left a split (`S7/`). The 10th frame is one token (`XX8`, `9/X`, `81`). Frames must add up to the score; the validator checks.
- Game order at Kingstown Bowl: the timer in the screen's top-left counts DOWN the lane's paid time, and the header color marks the game: green = game 1, yellow = game 2, red = game 3 (confirmed by Nick, week 1). A bowler shown "SKIP" at 00:00 ran out of time; log that game as `null`.
- Reading a scoring-screen photo: transcribe every frame you can read. If a frame is unreadable, log the game total only (no frames) for that game rather than guessing. Tell Nick which games you couldn't read.
- Use roster ids exactly. If a name in the photo isn't on the roster, ask before adding.
- Known aliases (Nick, Oct 22 2026): every profile shows a "Known aliases" row — the scoresheet name, the account username, and anything in `players[].aliases`. When a lane-screen name doesn't match, check names and aliases first. Once Nick confirms who a new lane name or nickname belongs to, add it to that bowler's `aliases` so it's matched automatically next time. The validator rejects an alias claimed by two bowlers. Aliases also link in free text (shit talk, stakes, recaps) via `linkNames`.
- Renamed bowler ids (Nick, Oct 28 2026): when a placeholder id gets renamed to a bowler's real id (e.g. `scooter` → `n8` after week 1), add the old id to that bowler's `formerIds` and the old display name to `aliases`. The account server moves every call-out, betcha, post, pick, scoresheet tag and team draw that still points at the old id over to the new one, and the site sends old ids (`#/player/scooter`) to the right profile. Never reuse a former id as a new bowler id; the validator checks.

- Printed scoresheets (Nick, Oct 28 2026): Kingstown Bowl's printouts (lane, game 1-4, every frame) are the scores database — log `events` from them and clear any live scores for that night (`liveAdd`). Ignore unfinished extra games (game 4). Keep every photo as proof on the `records` branch (orphan, not deployed, not shown on the site): `records/<date>/lane<N>-printout.jpg`. Note the repo is public on GitHub.

## Pick'em, call-outs, fun facts (Nick, Oct 21 2026)
- Stored by the account server (`picks`, `callouts` tables); scored in the browser from real results (`public/js/games.js`). Nothing to log by hand.
- Pick'em: top series 3 pts, lowest series 2 (full 3-game nights only, ties all count), any 200 game 1, each match to watch 1 (higher series). Picks lock at `league.startTime`; everyone's picks show after the lock.
- Call-outs: one bowler calls out another for the next night, optional 100-char trash talk. Higher series wins; no contest if either doesn't bowl. Max 3 per bowler per night; can take back before first ball.
- Ids matter: picks and call-outs use account player ids, so log scores under the same ids or they show as no contest / wrong.
- Betcha (Nick, Oct 24 2026): a bowler bets another for the next night with typed stakes ("loser buys a round"); the other takes it or chickens out before first ball. Higher series wins, only accepted bets count. Stored by the account server (`bets` table); shown on the home page (every open Betcha, just below the hero — moved there by Nick, Oct 24 2026), the ticker, profiles (Betcha button and form), the Players tab (Betcha button per card) and the night's results. Max 3 per bowler per night. Dollars on the purse (Nick, Oct 24 2026): the dollar amount is read from the stakes text (`E.stakesDollars`: "$5", "5 bucks", "ten dollars", "a fiver"; capped at $100; no number = no money). There's no separate dollar box. Once the night's scores are logged, `E.purse(data, nights, bets)` adds the amount to the winner's winnings only — Nick chose not to charge the loser. Shown in the Purse page's Betchas column, payout history and the night's results. Ties and no-shows pay nothing; betchas stay out of the buy-in pot. Settling up (Nick, Oct 25 2026): once scores are logged, the bell + pop-up tell the loser to pay up and the winner to watch for it; both stay lit until acted on. The loser taps "I paid" (`POST /api/bet/:id/paid`), the winner taps "Got paid" (`/got`); the server works out who won from league.json and stores `paid_at`/`got_at`. Dollars reach the purse only after BOTH confirm (`E.betSettled`); until then they show under "Betchas waiting to settle" on the Purse page and in "Settle up" on the Talk tab. If someone never taps, Nick can force it with `betcha.settled: [betId]` in league.json (ids from `/api/games`). Only the winner has to confirm (Nick, Oct 28 2026): `E.betSettled` is just `gotAt` (or `betcha.settled`); the loser's "I paid" is an optional heads-up and no longer stays lit. Dollars after the fact (Nick, Oct 28 2026): "+ add $" / "change $" on an accepted betcha with no dollar amount → `POST /api/bet/:id/amount {amount}` (0-100, 0 clears), either bowler in the bet until it's settled, Nick any time; stored in `bets.amount`, which beats the stakes text. Optional. Cents (Nick, Oct 28 2026): bets can be $2.50, "75 cents" etc. (`stakesDollars`/`bets.amount` keep cents, shown with `E.dollars`); the purse uses `E.betPurse` = rounded UP to whole dollars, no cents on the purse. Nothing else to log by hand — just log scores under the right ids.
- Talk tab, "Betchas & Shit Talk" (Nick, Oct 24 2026): replaced Results in the phone tab bar (Schedule moved to the More sheet). Signed-in bowlers post up to 200 chars, to everyone or aimed at one bowler (`posts` table, 10s between posts, authors can delete). Hide a post with `talk.hidden: [postId]` in league.json (ids come from `/api/games`). Newest betchas + shit talk show on the home page just below the hero.
- Notifications (Nick, Oct 24 2026): bell in the header + pop-up at the top of the screen, built in the browser (`public/js/talk.js`) from posts, call-outs, and only your own betchas (bet you, answered yours, settle up — Nick, Oct 25 2026: others' betchas show only on the Talk tab); the site checks every 45s while open. Last-seen time is stored per account (`seen` table) and in localStorage. Website only, no phone push yet. Needs-your-input items (Nick, Oct 27 2026): anything waiting on a signed-in bowler is `pending` and stays lit in the bell until they act: an unanswered league poll, the next night's attendance (worded as "Team night queue is open" on team nights), and a betcha aimed at them that's still open. Add any new thing that needs a bowler's answer the same way in `feedItems()`.
- Likes + comments (Nick, Oct 28 2026): every shit-talk post, betcha and call-out has a ♥ like toggle and a 💬 comment thread (`public/js/react.js`, `reactBar(kind, id)`; account server tables `likes`, `comments`; `POST /api/like {kind, id}`, `POST /api/comment {kind, id, msg}` (200 chars, 5s apart), `DELETE /api/comment/:id` by the author or Nick). Comments ping the bell of the bowlers in that post/betcha/call-out; likes ping nobody. Hide a comment with `talk.hiddenComments: [commentId]` in league.json.
- Dislikes (Nick, Oct 28 2026): 👎 next to ♥ on every post, betcha, call-out, and on each comment (kind `comment`). `POST /api/dislike {kind, id}` toggles; liking clears your dislike and vice versa (`dislikes` table, `/api/games` → `dislikes["kind:id"]`). Comments also have their own ♥ now.
- Badges in shit talk (Nick, Oct 28 2026): the shit talk section (home: newest 4, Talk tab: 20) lists every badge as it's earned, from logged nights plus tonight's live lane scores (marked Live*). Built in the browser (`badgeStrip` in talk.js); tapping one opens the badge popup.
- Fun facts: `public/js/facts.js`. One random fact on the home page and ticker each load. Only add facts you're sure are true.

## Attendance + team nights (Nick, Oct 25 2026)
- A bar at the top of every page (`public/js/attend.js`) asks signed-in bowlers "Confirm your attendance" Yes/No for the next night. Stored by the account server (`attendance` table, `POST /api/attend`), changeable until `league.startTime`. Yes = on that night's lineup (home page "Who's bowling") and in the team queue on team nights. The queue (photo + name of everyone who said Yes) lives inside the bar's "You're in" bubble, and the league poll sits in its old spot right under the hero (Nick, Oct 28 2026). The home panel now only shows the drawn teams after first ball.
- Nick is notified two ways: the bell (only for `league.commissioner`, set to `buggy`) and a phone push through ntfy.sh to topic `notify.ntfy` in league.json (env var `NTFY_TOPIC` overrides it). He subscribes to that topic in the free ntfy app.
- Team night: `teamNights["<date>"] = {}` (optional `teams: 3|4`; default 4 teams with 12+ in the queue, 3 with 6-11, else 2). At first ball a Durable Object alarm (or the first `/api/games` after) draws teams from everyone who said Yes: 4000 random splits, keep the most even (team mean of each bowler's last-9 average; new bowlers = queue average), pick one at random. Stored in `teamdraws`; never redrawn. Nick gets a push with the teams; bowlers get a bell notice.
- When logging a team night, copy the teams into the event as `"teams": [{"name", "pids"}]` (from `/api/games` → `teams[date]`; use the `Fetch roster`-style workflow or ask Nick). Walk-ins / fixes: edit that list, or before logging set `teamNights[date].override`. Validator checks every pid and no one on two teams.
- Draw time + Red vs Blue (Nick, Oct 28 2026): teams are drawn at `league.teamDrawTime` (19:05) so everyone's set up by first ball (19:15); per-night `teamNights[date].drawTime` overrides. The team queue (attendance) closes at the draw on team nights. `teamNights[date].names` fixes the team names (Oct 28: `teams: 2`, Team Red vs Team Blue; colors come from the color word in the name). A live team scoreboard (`homeTeamBoard()` in attend.js) sits at the very top of the home page once teams are drawn, scored from the live lane scores (`liveCalc`) and redrawn on every 45s poll.
- Team scoring (`E.teamResults`): each game a team scores its bowlers' handicap games (scratch + that night's `hdcp`). A team short of the biggest team's count that game gets a blind per empty spot = its own average handicap game that game. Two separate stats (Nick, Oct 28 2026 — "we track team wins differently"): **team wins** (`wins`, 1 per game to the highest team, ties split) and **total points** (`series`, all handicap pins). The site shows both and never combines them into one winner. The old placement `points` field is still computed but not shown. Individual night/points unchanged.
- Random lanes every week (Nick, Oct 28 2026): at the draw time (`teamDrawTime`) the server splits everyone who said Yes across `laneDraw.count` lanes (4) at random, random bowling order; on team nights each lane gets a mix of teams. Stored in `lanedraws`, never redrawn, in `/api/games` → `lanes[date]`; Nick gets an ntfy push. Real lane numbers for a night: `laneDraw.numbers["<date>"] = [17, 18, 19, 20]` (before the draw). Shown on the home page under the team board (`homeLaneBoard()`), plus an FAQ entry. Fewer lanes / redraw for one night: `laneDraw.nights["<date>"] = {count, rev}` — bumping `rev` makes the server redraw that night once (Oct 28: 3 lanes, rev 1).
- Final team board (Nick, Oct 28 2026): once a team night is logged, `homeTeamBoard()` shows that night's final Red vs Blue (FINAL · date, from `events`) until the following Monday, then it drops off. Placement (Nick, Oct 29 2026): the live board sits at the very top during the night; once the night is logged the FINAL board moves to just below the hero photo (`homeTeamBoard('below')`). Results page keeps the team panel for good.
- Trades after the draw (Nick, Oct 28 2026): `teamNights[date].swap: [[a, b]]` swaps two bowlers' teams; applied by the server to the stored draw (in `/api/games` and the lane mix). Oct 28: Fontes ↔ Liam.
